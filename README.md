# Max Payments — Institutional Fintech Website

Incluye Home institucional, Dashboard, Login/Sign Up demo, QR Payment demo, Multi-currency Wallet, Blockchain Transaction Explorer, Remittances, HSM/MPC/PQC architecture e Investor overview.

Videos:
- https://youtu.be/qvWjx91_C4s
- https://youtu.be/3CbAd5xZrtY

El proyecto es estático y está preparado para GitHub Pages. Los demos no mueven dinero ni almacenan credenciales.

“PQC-ready” es posicionamiento arquitectónico; no implica certificación, cumplimiento NIST, licencia financiera ni auditoría. Para producción deben definirse y auditarse algoritmos PQC, HSM/MPC, AML/KYC, privacidad, custodia y requisitos regulatorios.
